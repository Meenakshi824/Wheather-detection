🌦️ Weather Website

A simple and responsive Weather Web App built using HTML, CSS, and JavaScript. It allows users to check real-time weather information of any city across the world. The app fetches live data using a weather API and displays temperature, humidity, wind speed, and weather conditions with beautiful UI.

🚀 Features

Real-time weather updates using OpenWeather API

Search weather by city name

Clean and responsive design

Displays temperature, humidity, and wind speed

Dynamic weather icons and background updates

🛠️ Tech Stack

HTML5

CSS3

JavaScript (Fetch API)
